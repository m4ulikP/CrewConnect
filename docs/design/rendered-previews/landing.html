Zero race conditions

Most team builders check capacity in application memory before saving, allowing concurrent clicks to push a five-person team to six or seven members. CrewConnect anchors every join inside a MongoDB Snapshot Isolation transaction using an atomic conditional increment.

Requests carry a client-generated Idempotency-Key. The UI never decrements seats optimistically — it awaits authoritative server confirmation (HTTP 201) or displays an honest conflict notice (HTTP 409).
